About SentinelXAI

SentinelXAI is an intelligent Network Intrusion Detection System that combines a Random Forest classifier with Explainable AI to detect and explain malicious network traffic.

How It Works

Each prediction follows a transparent pipeline: the uploaded network-traffic sample is mapped onto the model's selected features, classified by the Random Forest, then explained with SHAP and LIME.

1. Upload Traffic

Provide a CSV of network-flow records matching the CSE-CIC-IDS2018 dataset schema.

2. Random Forest Detection

A trained Random Forest classifier scores each record across 30 selected features and predicts one of 9 traffic classes.

3. Explainable AI

SHAP reveals global feature importance and LIME explains individual predictions, making every decision transparent.

The Model

SentinelXAI uses a Random Forest classifier trained on the CSE-CIC-IDS2018 dataset. The model operates on 30 selected features and distinguishes 9 traffic classes: one benign class and eight attack types.

  • Algorithm: Random Forest
  • Features: 30 selected
  • Classes: 9 (1 benign + 8 attacks)
  • Dataset: CSE-CIC-IDS2018
  • Explainability: SHAP + LIME

Detected Attack Types

  • Benign
  • Bot
  • Brute Force - Web
  • Brute Force - XSS
  • DDOS attack-LOIC-UDP
  • DoS attacks-GoldenEye
  • DoS attacks-SlowHTTPTest
  • DoS attacks-Slowloris
  • SQL Injection

Explainability Methods

Two complementary XAI techniques make the model's decisions interpretable without altering the predictions themselves.

SHAP

SHapley Additive exPlanations measure each feature's contribution to a prediction. The summary plot on the Threat Analysis page shows the most influential features across the analysed sample.

LIME

Local Interpretable Model-agnostic Explanations fit a simple local model around a single prediction to show which features pushed it toward a given class.

Analytics

The Analytics page aggregates the latest run into attack distribution, frequency, and prediction confidence charts, all derived from real model output.
